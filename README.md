# 📘 CardápioTec

Sistema web para gerenciamento e consulta do cardápio escolar desenvolvido como projeto acadêmico da ETEC Fernandópolis.

O objetivo do projeto é fornecer uma plataforma intuitiva para que alunos, professores e funcionários possam visualizar o cardápio semanal da instituição de forma rápida, organizada e acessível.

---

# 🎯 Objetivos do Projeto

O CardápioTec foi idealizado para solucionar a divulgação do cardápio escolar, centralizando as informações em um ambiente digital moderno e de fácil utilização.

Entre os principais objetivos estão:

* Facilitar a consulta do cardápio semanal;
* Melhorar a comunicação entre a instituição e os alunos;
* Desenvolver uma aplicação Full Stack utilizando tecnologias atuais do mercado;
* Aplicar conceitos de desenvolvimento Front-End e Back-End estudados durante a formação técnica.

# 🏗️ Arquitetura do Projeto

O sistema será dividido em duas camadas principais:

### Front-End

Responsável pela interface visual e interação com o usuário.

### Back-End

Responsável por:

* Regras de negócio;
* Gerenciamento de usuários;
* Persistência dos dados;
* Comunicação com o banco de dados;
* Disponibilização de APIs REST.
